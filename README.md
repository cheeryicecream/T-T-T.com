# TTT League

A real-time online Tic-Tac-Toe game with:

- random matchmaking
- friend invites
- leaderboard
- login with email, username, and password
- profile pictures
- bot mode
- resign support
- 1-minute timer
- match history

## Local development

```bash
npm install
npm start
```

Open http://localhost:3000

## Production notes

This is a prototype app using local JSON storage for users and matches. For a production deployment, move to a real database and secure authentication.
